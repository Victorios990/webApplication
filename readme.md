Aqui sera desenvolvido e apresentada uma aplicação Web trabalhando com JAVASCRIPT 
para comportamentos e interatividade, HTML para a estrutura da página e para o 
conteúdo e CSS para apresentação e aplicação de estilos
<h1> onde trabalharei o meu cabeçalho
<p> onde serão trabalhados alguns paragrafos
<li> onde serão trabahadas nossas listas

Curiosidade= um atributo ID (usado no <p>) pode ser empregado para estilizar um elemento,.. 
...enquanto o atributo de classe (usado no <li>) é usado para estilzar todos os elementos da
...mesma classe.
    Cada elemento <li> de item de lista é agrupado em uma lista não ordenada <ul> (Unordered list)
